# Petit Jardin · landingspagina

Landingspagina voor Petit Jardin, een fictief theemerk. Gemaakt door Lore Deblauwer (DVG2B, Arteveldehogeschool) voor de periodeopdracht Creative Automation.

- Eén pagina: hero, verhaal, de vier smaken en de inschrijving voor de nieuwsbrief (MailerLite).
- Gebouwd met HTML, CSS en een beetje JavaScript, met hulp van Claude.
- Online via GitHub Pages.
